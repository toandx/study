1. What is Token?
AI Model don't read text directly
Text -> Tokenizer -> Token input -> AI -> Token output -> Text
Same text can have different token count than character counts.
Token are unit for input, output, cost and limit.
Cost = Token input + Token thinking + Token output.
Short prompt but unclear, more token thinking => Not cheaper
Tokenizer có bộ từ điển word - tokenID - embedding vector, đọc text input, chuyển nó thành dãy tokenID. 1 từ đa nghĩa đặt nhiều context khác nhau luôn map ra 1 tokenID.  

Specifically, tokens are the segment of text that are fed into and generated by ML model. These can be individual character, whole words, part of word, or even larger chunks of text. 

2. System prompts vs User prompt?
- System prompt define the AI's role, behavior and constraint (Work like AI Agent, can edit file, cannot read secret file)
- User prompt contains the task or question to be answers. 
- Model generate output by combining both promp.
- System prompt has higher priority than user prompt.

3. What is Chat completion API?
- Chat completion API is sending a request to Large language model. Request contain model deployment name (Sonet, Fable,...) and message payload (system prompt + user prompt)
4. Multi-modality and Multi-Modal model?
-Unimodal model only take 1 type of data as input, response 1 type of data as output.
- Multimodel model take multiple type of data as input (image, video), process together, enable richer understand by combine context accross input, generate mixed output.
